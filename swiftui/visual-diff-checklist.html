⬡ 三、组件库映射

14 个自定义组件，全面替换系统默认组件，统一视觉语言。

AppButton

主按钮组件，支持 primary / secondary / text / danger 四种风格，统一圆角和间距。

AppIconButton

图标按钮，支持 active / inactive 状态切换，带高亮背景与阴影变化。

AppCard

基础卡片容器，带边框 + 阴影，圆角可配置，用于内容区块包裹。

AppCardHover

交互卡片，hover 时边框高亮 + 阴影增强 + 轻微上移（lift），用于可点击卡片列表。

AppPanel

面板容器，包含标题栏 + 分割线 + 内容区，用于设置页等场景。

AppInput

输入框组件，基于 TextField，带 focus ring 焦点指示和自定义占位符样式。

AppBadge

文字徽章，支持自定义背景/前景色，预设 H5 / PC / Dashboard / Electron 四种平台色。

AppSegmented

分段选择器，支持多标签切换，选中态带 primary 背景和阴影。

AppDivider

分割线组件，支持自定义颜色和间距，用于区块分隔。

AppEmptyState

空状态展示，包含图标 + 标题 + 描述，用于无数据时的友好提示。

AppSidebar

侧边栏容器，200px 宽度白色背景，包含导航项列表。

AppNavItem

导航项，带圆点指示器，选中态有高亮背景和图标变色。

AppTopBar

顶部栏，52px 高度，包含 macOS 红绿灯按钮 + 搜索框 + 窗口标题。

WindowControls

macOS 红绿灯按钮模拟（关闭 / 最小化 / 最大化），配色与原生一致。

! 四、已知问题与待办

需要后续跟进的问题清单，按严重程度排列。

  • ✕
    深色模式未完成适配

    DesignTokens 仅定义了 Dark 色板，但各视图代码尚未根据 ColorScheme 自动切换颜色。需要为所有视图添加浅色/深色条件判断。

  • ✕
    动画未完全应用

    hover / 选中态动画已在组件中定义（如 AppCardHover 的 lift 效果），但部分视图（如 RootView 侧边栏导航项切换）尚未添加过渡动画。

  • !
    截图对比待执行

    需要 Electron 版与 SwiftUI 版并排截图，逐项核对布局偏移、色彩偏差、字号差异、间距精度。建议至少覆盖 8 个核心页面的完整截图。

  • !
    字体回退策略

    Electron 原版使用思源黑体（Source Han Sans SC），macOS SwiftUI 版已配置 PingFang SC 为首选字体。两者在同等字号下的渲染宽度可能略有差异，需要实测关键页面是否出现换行错位。
